# CampusWheels

This project models a simple campus vehicle rental desk using object-oriented programming.

## How to run

Open a terminal in the Assignment_02 folder and run:

```bash
python main.py
```

## Included classes

- Vehicle
- Renter
- ElectricCar
- Motorbike

## AI use note

I used AI only to explain object-oriented programming concepts and to confirm expected behaviour. I wrote the class definitions and program logic myself.
